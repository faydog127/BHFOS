## Permission terminology

### Dashboard (what the Founder selects when creating the OAuth app)
Per official OAuth scopes docs (fetched 2026-07-17), scopes are set in the
Supabase Dashboard when creating/editing an OAuth app as category + Read/Write
pairs. For Option A the Founder selects **only**:

| Dashboard label | Type | Official description includes (non-exhaustive) |
| --- | --- | --- |
| **Projects** | **Read** | Retrieve a project's metadata; check upgrade eligibility; retrieve network restrictions; retrieve network bans |

Wire / OAuth application scope string corresponding to that selection:
**`projects:read`**

**Do not select** (examples): Projects Write; Auth; Database; Domains; Edge
Functions; Environment; Organizations; Rest; Secrets; Storage; Analytics (or any
other Read/Write pair).

### Management API permission identifiers (docs / endpoint FGA — not Dashboard checkboxes)
Examples that appear in Management API documentation and must **not** be treated
as alternate Dashboard choices for the same control:

- `projects_read`
- `project_admin_read`
- (and other endpoint permission ids such as `edge_functions_read`,
  `analytics_logs_read`, `database_read`, …)

These identifiers describe which endpoints the platform may authorize under a
granted capability. They are **not** interchangeable synonyms for the OAuth
scope string `projects:read`, and the Founder does not “pick `projects_read`
instead of `projects:read`” in the OAuth app UI.

## Effective access under Projects Read

**Projects Read / `projects:read` may enable multiple project-related read
endpoints** beyond the adapter allowlist (metadata, upgrade eligibility, network
restrictions, network bans, and related project reads as documented). That is
**platform-effective access** of the token under that scope.

The adapter must nevertheless expose **only** the approved allowlist (initially):

| Operation | Method + path | Status |
| --- | --- | --- |
| Project metadata/status | `GET /v1/projects/{ref}` with `{ref}=wwyxohjnyqnegzbxtuxs` only | **allowed** |
| Project health | `GET /v1/projects/{ref}/health` | **allowed only if required and verified** (docs-verified path; included for non-sensitive health metadata) |

The adapter must **reject** (non-exhaustive; enforced by fixed ops + deny rules):

- project listing (`GET /v1/projects` and equivalents)
- organization project listing
- network restrictions / network bans
- upgrade eligibility / upgrade operations or information not required
- database endpoints
- Edge Function endpoints (including inventory and `/body`)
- logs / analytics
- secrets / API keys
- Auth configuration
- SQL
- migrations
- all writes
- any agent-controlled URL, path, query, project ref, or HTTP method that would
  bypass the allowlist

## OAuth credential lifecycle (required)

| Concern | Required behavior |
| --- | --- |
| Access-token expiration | Treat access tokens as **short-lived** (platform-controlled TTL). Adapter must fail closed on `401`/`Unauthorized`. |
| Refresh behavior | Adapter (or Diagnostics-only refresh helper) may use `I2_SUPABASE_OAUTH_REFRESH_TOKEN` + client credentials against `POST /v1/oauth/token` (`grant_type=refresh_token`) to mint a new access token; rotate stored access token + expiry; never expose refresh/access tokens to the agent. |
| Client-secret rotation | Rotate `I2_SUPABASE_OAUTH_CLIENT_SECRET` in Dashboard; update Diagnostics env only; re-authorize if platform requires; revoke old secret. |
| Authorization revocation | Founder revokes the OAuth app authorization in Supabase; access and refresh cease. |
| Refresh-token revocation | Follows authorization revocation / app disable; clear refresh token from Diagnostics env. |
| Adapter shutdown | Stop adapter process; unset live env; confirm no child process retains tokens. |
| Removal from Diagnostics environment | Delete all `I2_SUPABASE_OAUTH_*` and `SUPABASE_DIAGNOSTICS_PROJECT_REF` entries from the Diagnostics secret env. |
| Audit attribution | Management API calls attributable to the **OAuth app** identity (not a founder-personal PAT). |
