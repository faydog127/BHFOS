## Operational problem
G2.3A delivered repository foundations, but Production Diagnostics (I2) still has
**no approved access specification, runbook, reconciliation attestation schema,
execute-sql review artifact, or provisioning/revocation checklists**. Without
these, the founder remains the default log reader / inventory auditor / schema
investigator, and any live provisioning would be unbounded.

Separately, six reconciliation blockers (Edge Function inventory mismatch, schema
drift, execute-sql authority, branch protection, production-log availability,
secret-storage/revocation) remain unresolved. They cannot be cleared by
repository docs alone — but they also must not be attacked with standing admin
credentials under a vague authorization.

## Proposed correction (B1 only — repository-only)
Authorize the Builder to implement the **exact B1 file set** in brief Section 14:
diagnostics access + masking policy, reconciliation attestation scaffold,
diagnostics runbook, execute-sql review checklist artifact, I2 provisioning and
revocation checklists, diagnostics evidence template, and names-only secret-
inventory rows for *planned* I2 tokens — plus Baton/Ledger progress records.
**Validate, open a PR, obtain Architecture Guard review.** No credentials. No
production access. No tool binaries required in B1.
