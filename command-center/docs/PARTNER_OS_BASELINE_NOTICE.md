This branch preserves the existing BHFOS service-company product work as the starting baseline for **Partner OS**.

Partner OS is the BHFOS product for **Service Partners**. Existing CRM, field-service, scheduling, dispatch, inspection, evidence, MIL, reporting, financial, communication, automation, and related work on this branch remains available for future Partner OS improvement.

This branch is not the Network OS product line and should not receive Network OS-specific repurposing changes.

The stated BHFOS end state is controlled interoperability between independent products:

**Partner OS ↔ Network OS**

Neither product is required to depend on the other to operate independently.
